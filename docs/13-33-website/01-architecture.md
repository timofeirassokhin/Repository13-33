# 13-33.pro — архитектура и логические шаблоны

## 1. Зонтичная структура

```
13-33.pro                       ← Духовно-психологическое Пространство (default)
13-33.pro/expert                ← Экспертное Пространство (онлайн-бизнес)
admin.13-33.pro                 ← Payload админка (за VPN/IP)
api.13-33.pro                   ← публичный API (если понадобится для интеграций)
```

Переключатель «Духовное ↔ Экспертное» в правом верхнем углу шапки. Кросс-ссылки между пространствами через теги. Стилистическая поднастройка (палитра-вариант, иконки) — но базовая дизайн-система общая.

## 2. Контент-модель (Payload коллекции)

### Сквозные таксономии

| Коллекция | Назначение | Примеры |
|---|---|---|
| `topics` | Темы (предметные области) | психология, телесность, энергии, традиции, философия, отношения, дыхание, голос |
| `requests` | Запросы клиента | здоровье, карьера, отношения, поиск себя, тревога, кризис, родительство, деньги |
| `methods` | Методы работы | КПТ, гештальт, телесная терапия, шаманские практики, дыхательные практики |
| `formats` | Форматы для журнала | эссе, разбор, интервью, дневник практики, обзор, манифест |

### Контентные коллекции

| Коллекция | Поля (ключевые) | Связи |
|---|---|---|
| `articles` | title, slug, type (longread/blog), excerpt, body (lexical), cover, published_at, reading_time | author→experts, topics[], requests[], methods[], related_products[] |
| `experts` | name, slug, role, bio, photo, contacts, calendar_link, telegram | methods[], products[] (как автор), articles[] (вычисляемая) |
| `products` | title, slug, type (course/event/session/group), short_desc, hero_image, price, getcourse_url, gallery[], schedule, format | topics[], requests[], methods[], experts[] (авторы), related_products[] |
| `events` | title, slug, date, time, location (Арбат | онлайн), capacity, price, getcourse_url, photos[], report_body | experts[], topics[], related_products[] |
| `quizzes` | title, slug, intro, questions[], result_logic, cta_offer | recommended_products[], recommended_articles[] (через теги) |
| `pages` | title, slug, body, layout_blocks[] | — для статичных страниц (О нас, миссия, Арбат-главная) |

### Сервисные

- `users` — для ЛК (V2)
- `media` — изображения, файлы
- `redirects` — на случай переезда URL
- `nav` — кастомное меню (чтобы редактор мог поправить)
- `site_settings` — глобальные тексты, телефоны, соцсети, дисклеймеры

## 5. Сквозные элементы (на каждой странице)

### Header (sticky)
- Лого 13-33 (ведёт на `/` соответствующего пространства)
- Главное меню
- Поиск (открывает оверлей)
- Кнопка профиля → ссылка на GetCourse в V1, ЛК в V2
- Переключатель Пространств

### Sidebar-баннер квиз-навигатора
Показывается на всех страницах журнала, тем, запросов, методов (там, где уместно сбоку). Микро-блок: «Не знаете с чего начать? Тест-навигатор за 3 минуты подберёт ваш трек». CTA → `/quiz/navigator`.

### Карусель «созвучных продуктов» (footer-блок)
В нижней части страниц журнала, тем, методов, запросов. 4-6 карточек, скролл по горизонтали. Алгоритм: совпадение тегов с текущей страницей → score → топ-N.

### Слайдшоу афиш
На главной и в подвале сервисных страниц. Афиши событий Арбата + новые продукты. Автопрокрутка с пиктограммами «Событие» / «Новый курс» / «Лонгрид».

### Footer
- Подписка (форма → GetCourse)
- Соцсети
- Меню всех разделов
- Юридика (политика, оферта, дисклеймеры)
- Копирайт + товарный знак
- Переключатель пространств (повтор)

## 7. Граф связей (механика)

Все объекты имеют **многосторонние связи через таксономии** (`topics[]`, `requests[]`, `methods[]`).

### Алгоритм «связанные»

Для текущего объекта X с тегами T(X) считаем для каждого кандидата Y:

```
score(Y) = |T(X) ∩ T(Y)| × weight(совпадающие_теги) − recency_penalty
```

Кандидаты ограничиваем по типу (если страница темы → ищем продукты + статьи + эксперты + события). Кеш на 1 час, инвалидируется при публикации новой записи.

### Аналитика графа (V1)

- Plausible custom events: клик по карточке, открытие квиза, прохождение шага квиза, переход на GetCourse
- На каждом теге — счётчик показов и кликов (даст понять, какие темы/запросы тянут трафик)
- Дашборд в Payload админке: топ-пары тегов (что часто совпадает), мёртвые теги, сироты-объекты без связей

## 8. Дизайн-система (соответствует 13-33 LOGOBOOK)

### Палитра (точные значения из логобука)

| Токен | Имя в гайде | Pantone | HEX | Применение |
|---|---|---|---|---|
| `--c-primary` | ОСНОВНОЙ | 433 | `#1E252D` | Основной фон сайта, тёмные плашки |
| `--c-vanilla` | ВАНИЛЬНЫЙ | 155 | `#EAD0A6` | Контентные карточки, лого на тёмном, светлые блоки |
| `--c-coral` | КОРАЛЛОВЫЙ | 2024 | `#EB8260` | **Основной CTA**, акценты, тег «новое» |
| `--c-blue` | СИНИЙ | 2168 | `#2B495B` | Вторичные кнопки (Telegram-bot и пр.), теги |
| `--c-teal` | ГОЛУБОЙ | 624 | `#7C9C90` | Теги тематик «природных», вторые акценты |
| `--c-brick` | КИРПИЧНЫЙ | 174 | `#8B3F28` | Цены, акценты «земляного» характера, теги «событие» |
| `--c-olive` | ОЛИВКОВЫЙ | 7760 | `#8E843D` | Теги «продукт/курс», третьи акценты |

**Дефолтная схема сайта**: тёмная (`--c-primary` фон + ванильные карточки + коралловый CTA). Это та же стилистика, что в GetCourse-макетах из логобука.

**Как используется в Экспертном Пространстве**: тот же набор, но смещение акцентов — больше синего/оливкового, меньше кораллового, больше «делового» воздуха.

### Типографика

| Роль | Шрифт | Применение |
|---|---|---|
| Display (hero, крупные H1/H2) | **Bebas Neue Bold** | Hero-заголовки, секционные H2, дисплейные числа |
| Display alt / UI капс | **Bebas Neue Book** или **DIN 2014** | Меню, теги, подписи, кнопки |
| UI body | **DIN 2014** | Подзаголовки, навигация, формы |
| Длинный текст | **Myriad Pro** | Тело статей, лиды, описания |
| Цифры в логотипе | классический Old-style serif (по гайду — сохранить как в лого) | Только в логотипе и крупных декоративных вставках («13», «33» как графические элементы) |

В прототипе DIN 2014 заменён на **Barlow / Barlow Condensed** (visually-closest fallback в Google Fonts), Myriad Pro — на **Source Sans 3**, цифры лого — на **Bodoni Moda**. В проде подключить лицензированные DIN 2014 + Myriad Pro через `@font-face`.

### Сетка

- Контейнер: 1280px max
- Padding: 16px (mobile) → 24px (tablet) → 32px (desktop)
- Колонки: 12-col grid, gap 24px
- Брейкпоинты: 360 / 768 / 1024 / 1280 / 1440

### Ритм

- Базовый шаг: 8px (все отступы кратны 4 / 8)
- Воздух между секциями: 96-128px на desktop, 48-64px на mobile
- Hero — щедрое «дыхание», крупные шрифты в плакатном масштабе

### Скругления (унаследовано из GetCourse-макетов)

| Токен | Значение | Применение |
|---|---|---|
| `--r-sm` | 8px | Поля ввода, мелкие элементы |
| `--r-md` | 16px | Маленькие карточки, плашки |
| `--r-lg` | 24px | Контентные карточки (статья, продукт) |
| `--r-xl` | 32px | Крупные плашки (header-pill, hero-блоки, баннеры) |
| `--r-pill` | 999px | Кнопки, теги, переключатели |

### Тени

- `--shadow-card`: `0 8px 32px rgba(0,0,0,0.3)` — приподнятые карточки на hover
- `--shadow-pill`: `0 4px 16px rgba(0,0,0,0.25)` — header и крупные плашки

### Иконография

Из логобука получены готовые пиктограммы (`13-33 GK PICTO.pdf`):

- ПРОФИЛЬ · ОБУЧЕНИЕ · ПОДДЕРЖКА · ПОКУПКИ · ЦРМ · САЙТ · УВЕДОМЛЕНИЕ · МОБИЛЬНАЯ ВЕРСИЯ · ИНСТРУКЦИЯ
- Контентные: ПИШИТЕ ОТ РУКИ · ПРОЧТИТЕ ВНИМАТЕЛЬНО · ТВОРЧЕСКИЙ ПОДХОД · СНЯТЬ ВИДЕО НА СМАРТФОН · ОБРАТИТЕ ВНИМАНИЕ · ПРОСМОТР ЗАЙМЁТ
- Соцсети: Telegram · Чат

**Стиль**: тонкие линейные иконки в одинаковом весе штриха (~2-3px), без заливок, в `--c-primary` (на ваниле) или `--c-vanilla` (на тёмном). Подписи под иконкой капсом DIN 2014 / Bebas.

Эти пиктограммы — основа иконографического языка сайта: используются в карточках продуктов, навигационных блоках, инструкциях, ЛК.

Декоративные элементы (паттерны Уильяма Морриса с лиственным орнаментом из логобука) — для фоновых текстур больших баннеров и hero-секций. Использовать дозированно.

### Тон визуала

- **Плашки**: pill-shaped header (большое скругление), карточки контента — ванильные на тёмном фоне (как в GetCourse-макетах)
- **Контраст**: высокий — тёмный фон vs ванильные карточки vs коралловые CTA
- **Декоративные числа**: гигантские «13», «33», «01», «02» полупрозрачные на фоне секций — фирменный приём (видно в логобуке)
- **Прозрачность плашек**: при наложении на фоновые узоры/паттерны допустимо снижение до 80-70% (подтверждено в GetCourse-гайде)
