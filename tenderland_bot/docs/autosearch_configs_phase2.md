## Универсальный шаблон автопоиска (повторяем для каждого)

```
AND:
  ├─ OR:
  │   ├─ «По документации» (tender_files)     — короткий список из самых специфичных маркеров
  │   ├─ «Название тендера» (tender_name)     — основной полный INCLUDE
  │   └─ «По извещению» (tender_notification) — то же что в tender_name (для шире охвата)
  ├─ «Исключения» (tender_keywords_exclude)
  └─ «Статус тендера» = «Активные»             (значение 1)
```

**EXCLUDE — общий для всех 5 автопоисков ниже.** Содержит «дорожников», «гипохлорит», «договоры ГПХ», «огнезащитную обработку» и прочий шум который мы нашли при отладке.

## 7. Что после активации Search/Find

Все 5 INCLUDE/EXCLUDE-конфигов превращаются в JSON-файлы в `gluvex_tender_machine/config/searches/`:

```
config/searches/
├── analytics_instruments.json        (Test 4b — приборы аналитики)
├── chromatography_consumables.json   (новый из главы 1)
├── molecular_instruments_panels.json (новый из главы 2)
├── molecular_consumables.json        (новый из главы 3)
├── general_lab_equipment.json        (новый из главы 4)
└── _shared/
    ├── common_exclude.txt            (шапочный EXCLUDE из этого файла)
    ├── pcr_exclude.txt               (только для молекулярных)
    └── consumables_exclude.txt       (для расходников)
```

CLI шлёт каждый конфиг как POST в `/Search/Find` параллельно, агрегирует результаты в Postgres с дедупом по `tender_id`, маркирует тендеры по `pipelines: ["analytics" | "consumables" | "molecular_instruments" | ...]`.
