### 3.3. AI-слой — финальное решение «2 модели»

#### Локальная LLM (основная, 90% задач) — **Qwen 2.5 14B Instruct Q4_K_M**

Запускаем через **Ollama** или **vLLM** на CPU нашего VPS (16 vCPU / 64 GB).

**Размер:** 9 GB RAM в Q4-квантизации.
**Скорость на 16 vCPU:** 8-12 токенов/сек.

Что делает:
- Парсинг транскриптов звонков менеджеров → извлечение требований клиента
- Парсинг присланных методик (Word с детекторами, мощностями, спецификациями) → структурирование ТТХ
- Извлечение характеристик из ТЗ тендеров → JSON со списком {характеристика, значение, единица}
- Матчинг с каталогом продукции → подбор аналогов из портфеля Gluvex
- Классификация и роутинг входящих документов
- Ответы менеджеру в боте Telegram/Yandex Messenger (5-15 сек на ответ — приемлемо)

Почему Qwen 14B (а не 32B):
- На CPU без GPU 32B даёт 2-3 t/s — **слишком медленно** для production
- 14B Q4 даёт 8-12 t/s — **рабочая скорость** для batch и приемлемая для бота
- Качество 14B всё ещё высокое на русском, понимает технические спецификации
- Размер 9 GB укладывается в RAM с большим запасом

**При апгрейде до VPS+GPU** — можно перейти на Qwen 32B Q4 (30-50 t/s на GPU 16-24 GB).

**Альтернативы рассмотрены и отклонены:**
- Qwen 32B Q4 без GPU — медленно (2-3 t/s)
- Llama 3.3 70B Q4 — нужно 40 GB RAM Q4, но скорость на CPU < 1 t/s
- Gemma 2 9B/27B — русский слабее Qwen
- DeepSeek V3 (671B MoE) — локально не запустишь

#### Внешний LLM (резерв, 10% задач)

**Модель: Anthropic Sonnet** через **OpenRouter** (LiteLLM прокси).

Что делает:
- Длинный контекст 100K-200K (большие ТЗ или комплексные методики)
- Сложный матчинг с тонкостями нюансов русского
- Fallback при недоступности локального GPU
- Периодическая валидация качества: раз в неделю прогоняем 10 контрольных матчингов через Sonnet и сравниваем с Qwen — если расхождение > 10%, тюним Qwen-промпт

**Почему не DeepSeek V3 как резерв:** DeepSeek V3 дешевле (~$0.27/M input), но имеет ru-блокировки доступа и качество русского чуть ниже Sonnet. На редкие сложные кейсы лучше доплатить за Sonnet — это даёт гарантированный fallback.

**Cost:** при 90% локально + 10% Sonnet → **~$10-30/мес** на API (вместо $150-200 если бы всё на API).

### 3.4. Транскрипция аудио

| Слой | Модель | Когда |
|---|---|---|
| **Основной** | **faster-whisper large-v3** локально на CPU/GPU | По умолчанию |
| **Fallback** | **Groq Whisper Large v3 Turbo (free tier)** | При недоступности локального или для real-time когда менеджер ждёт ответа в боте |

> 🧪 **Помечено для тестирования:** реальное число звонков и их длина. Возможно при 100-200 звонках/мес сложного качества хватит даже **medium**-модели локально. Проверить в первые 2-4 недели после запуска.

**Cost:** **$0/мес** (локально) или **$0** (Groq free tier до 7200 запросов/день).

## 6. Как принимаем решение GPU/без GPU после тестов

После 4-8 недель работы у нас будут **реальные метрики**. Триггеры для апгрейда (добавления GPU-сервера):

| Метрика | Если измерим > | → Решение |
|---|---|---|
| Реальное число КП/мес | 700+ | Добавить GPU-сервер |
| Латентность ответа бота менеджеру через локальный Qwen 14B | > 15 сек | Апгрейд до Qwen 32B на GPU |
| Скорость batch-обработки тендеров на Qwen 14B CPU | < 30 тендеров/час | GPU нужен для масштабирования |
| API-стоимость Sonnet через OpenRouter / мес | > $80 | GPU окупится за 8-12 мес |
| Стабильность связи с OpenRouter из РФ | < 99% | GPU критичен (автономность) |
| Реальное число звонков для транскрипции | < 200/мес | Whisper локально на CPU достаточно |
| Реальное число звонков для транскрипции | > 1500/мес | Whisper нужен на GPU для скорости |
| Качество Qwen 14B на матчинге (на 10 контрольных) | < 80% точность | Нужен 32B на GPU для качества |

## 9. Ключевые архитектурные решения этого документа

| Решение | Обоснование |
|---|---|
| **Selectel** как провайдер | Локация в РФ, IP не блокируется русскими сервисами, поддержка нормальная, есть линейка GPU-серверов для апгрейда |
| **Один Postgres-инстанс с разными БД** для Twenty/MemPalace/Gluvex | Меньше overhead, проще бэкапить, но БД изолированы |
| **2 модели в работе:** Qwen 2.5 14B локально на CPU + Sonnet API резерв | Устраняем «чехарду с моделями». Qwen 14B покрывает 90% задач на русском, Sonnet — для длинного контекста и крайних случаев |
| **Whisper локально + Groq fallback** | Бесплатно, контролируемо, не зависим от связи с США |
| **Старт без GPU, апгрейд через 1-2 мес после метрик** | Не вкладываемся в GPU не зная реального профиля нагрузки. Решаем по данным. |
| **Почта и хранение документов через существующий Google Workspace** | Уже оплачен у заказчика, менеджеры привыкли. Не добавляет новых расходов. SMTP через Gmail для рассылок, Drive для архива и КП, Calendar для напоминаний |
| **Backup на Google Drive** (часть Workspace) | Бесплатно (включено в Workspace), интегрируется с привычным UI менеджеров |
