Это самая первая страница `13-33.pro`. Сайт собирается из markdown-файлов в
`infra/sites/13-33.pro/site/src/content/posts/` — добавил файл, закоммитил,
пересобрал — и страница опубликована.

## Как добавить страницу

1. Создай файл `slug-страницы.md` в каталоге `posts/`
2. Заполни шапку:

   ```yaml
   ---
   title: Заголовок
   description: Краткое описание (опционально)
   date: 2026-05-01
   tags: [тег1, тег2]
   ---
   ```

3. Дальше — обычный markdown.
4. На сервере: `cd /opt/stack/Repository13-33/infra/sites/13-33.pro && docker compose up -d --build`

Готово, новая страница доступна по адресу `/slug-страницы/`.
