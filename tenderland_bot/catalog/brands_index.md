## Стратегия парсинга для каталога Gluvex Tender Machine

### Фаза A (сейчас, обзорная)

1. ✅ **Brands index** (этот документ)
2. ⏳ **Карточки по 10 ключевым брендам** — Memmert, Sartorius, Metrohm, SOTAX, Schmidt+Haensch, AmoyDX, Illumina, CAMAG, Sciencix, Hawach. Через WebFetch — выборочные обзоры подкатегорий.

### Фаза B (на VPS после развёртывания)

Полноценный Python-парсер сайта:

```
catalog_parser/
├── fetch_brands.py        # https://gluvexlab.com/brands/ → JSON списка
├── fetch_brand_products.py # /brands/<slug>/ + пагинация → список карточек
├── fetch_product.py        # карточка товара → структурированный JSON
├── normalize.py            # нормализация в схему products таблицы
└── load_to_db.py           # загрузка в Postgres
```

Запускается ежедневно через ARQ-крон. Поскольку Agilent имеет 50 000+ товаров, парсер должен:
- Использовать пагинацию (вероятно `?page=N`)
- Кэшировать неизменные карточки (не дёргать каждую каждый день)
- Обновлять только дельту (по дате модификации в HTML, если есть)
- Уважать robots.txt и rate-limit (1 запрос в 2-3 секунды)

### Что в итоге будет в Postgres `products` таблице

Из ~60 000 позиций ожидаемо извлечём:
- **Аналитика приборы:** ~500-1000 (Agilent + Shimadzu, отфильтровать запчасти и расходники)
- **Расходники хроматографии:** ~3000+ (Gluvex собственный бренд + Sciencix + Hawach + MN)
- **Молекулярка:** ~1000 (Illumina + AmoyDX)
- **Общелаб:** ~1000 (Memmert + Sartorius + остальные общелабовцы)
- **Прочее (для расширения портфеля):** оставить в БД с пометкой `is_active=false`, при необходимости активировать

### Связь с автопоисками Tenderland

Каждая запись `products` будет иметь поле `applicable_search_topics: TEXT[]`:

| Топик автопоиска | Бренды из каталога Gluvex |
|---|---|
| `analytics_instruments` | Agilent, Shimadzu, CAMAG, Hawach |
| `chromatography_consumables` | Gluvex (свой), Sciencix, Macherey-Nagel |

Это позволит на этапе матчинга **сразу фильтровать кандидатов** по топику тендера, не прогоняя весь каталог.

### Illumina (899 позиций) — РАСХОДНИКИ, не приборы! ⚠️

Главный инсайт парсинга:

**Reagent kits (основное):**
- MiSeq Reagent Kit v2 (300 циклов): Micro / Nano / стандарт
- NovaSeq 6000 S4 Reagent Kit v1.5 (200 циклов)
- NovaSeq 6000 S2 Reagent Kit v1.5 (100 / 200 циклов)
- Illumina DNA Prep with Enrichment (16 samples)
- PhiX Control v3
- Illumina Purification Beads
- Illumina CovidSeq v4 Primer Pools

**Microarrays:**
- Infinium ImmunoArray-24 v2 BeadChip Kit

> **Критический вывод:** **Gluvex поставляет Illumina-РАСХОДНИКИ, не сами секвенаторы.** Это меняет матчинг для домена молекулярки:
>
> - Тендер на **поставку секвенатора NovaSeq/MiSeq** → мы НЕ предлагаем прибор, но можем предложить пакет расходников к нему первого года.
> - Тендер на **реагенты к Illumina** (S4 kit, MiSeq Reagent Kit, library prep) → отлично, прямой матч.
> - Тендер на **library prep** (Illumina DNA Prep, AmpliSeq) → прямой матч.
>
> Для Hot Pipeline 2 (`Молекулярка_приборы_панели`) надо помечать что наш ответ = «поставка реагентов и расходников», а не «поставка прибора».

### Buchi — НЕТ в каталоге ❌

Подтверждено отсутствие Buchi в портфеле Gluvex. Из автопоиска `Общелаб_оборудование_v2` ключи `Buchi` оставляем **только для Market Intelligence** — мы не участвуем в тендерах на Buchi-приборы напрямую.

**Главное открытие:** Gluvex — это в первую очередь **Agilent + собственный бренд расходников + общелаб**. Молекулярка (Illumina/AmoyDX) — узкая ниша, в основном расходники. Waters/Thermo MS, MGI/BGI/PacBio/ONT, Buchi — отсутствуют.

Это **меняет логику матчера** — для тендеров с указанием «не нашего» бренда мы либо:
1. Предлагаем альтернативный бренд из нашего портфеля (если у них допустим эквивалент)
2. Отказываемся от участия (если ТЗ жёстко привязано к бренду)
3. Предлагаем расходники к их прибору (если есть в наличии)
